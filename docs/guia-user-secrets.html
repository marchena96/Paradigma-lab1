User Secrets en ASP.NET Core

Guía visual — Proyecto HackerRank1 (LibraryService API) · cómo guardar la contraseña sin subirla a git

1. El problema

Si escribes la contraseña de Supabase en appsettings.json, queda pública en GitHub (git guarda el historial). User Secrets es un cajón secreto que solo existe en tu máquina.

3. Las tres piezas que se conectan

🪪 Etiqueta (csproj)

El GUID que conecta el proyecto con su cajón.

✓ Sí sube a git (no es secreto)

🔒 Cajón (secrets.json)

%APPDATA%\Microsoft\UserSecrets\9cbbfeab-…-a68ef6\secrets.json

Archivo JSON fuera del proyecto, en la carpeta del usuario.

✗ Nunca sube a git

📋 Cartelera (appsettings.json)

HackerRank1/appsettings.json:3

Estructura visible con el placeholder [SUPABASE-PASSWORD].

✓ Sí sube a git (sin secretos)

La carpeta del cajón se llama igual que el UserSecretsId: así es como el sistema encuentra el archivo correcto.

4. Qué pasa al ejecutar dotnet run

Se compila. El compilador ve el UserSecretsId en el csproj.
Detecta que el entorno es Development (definido en launchSettings.json).
Localiza el cajón: %APPDATA%\Microsoft\UserSecrets\<UserSecretsId>\secrets.json.
Suma las capas: appsettings.json → Development → User Secrets → entorno.
Startup.cs lee la cadena; la capa User Secrets reemplaza el placeholder → conexión real a Supabase. 🎉
⚠️ En Producción User Secrets nunca se cargan. Las credenciales deben ir en variables de entorno o un secreto del hosting.

5. Cheat sheet de comandos

Todos se ejecutan dentro de la carpeta del proyecto (por eso "desde HackerRank1/": ahí vive el csproj con el UserSecretsId).

AcciónComando
Guardar / sobrescribirdotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=...;Password=..."
Ver qué hay guardadodotnet user-secrets list
Borrar una clavedotnet user-secrets remove "ConnectionStrings:DefaultConnection"
Desde la raíz de la solucióndotnet user-secrets set ... --project HackerRank1/HackerRank1.csproj
📌 Regla de oro: estructura en git, secreto en tu máquina. En otra computadora hay que repetir dotnet user-secrets set ... (sección 7.1 del doc técnico).
